# Webitro

**Custom software studio from Türkiye.** We design and build the software you have in mind, from AI agents and chatbots to automation, e-commerce and games, and we deliver it working. It runs wherever you need it: your own computer, your server, or the cloud.

🌐 [webitro.com](https://webitro.com) · 💼 [LinkedIn](https://www.linkedin.com/company/webitro-software/) · 📷 [Instagram](https://www.instagram.com/webitrosoftware/) · ✉️ info@webitro.com

## What we build

- **AI agents and orchestration**: agents tailored to your data and tools, and multi-model systems that split a request into steps and finish the job
- **Bots**: WhatsApp, Telegram and Discord bots that answer questions, take bookings and orders
- **Automation and autonomous systems**: lead finding, content engines, social media and SEO/GEO pipelines that run without manual work
- **Document and legal AI**: semantic search and analysis over contracts, rulings and internal docs
- **E-commerce**: stores with AI-assisted product upload and a single admin panel
- **Games**: browser and desktop games built from your idea
- **Claude Code skills**: custom skills and command sets for teams using AI coding assistants
